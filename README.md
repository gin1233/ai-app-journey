## 环境要求

- Python >= 3.12（当前使用 3.14.7）
- Git
- VS Code

## 快速开始

    # 1. 创建虚拟环境
    python -m venv .venv

    # 2. 激活虚拟环境（PowerShell）
    .\.venv\Scripts\Activate.ps1

    # 3. 运行环境自检
    python day01\check_env.py
